# RFC 0112：qbench 负载枚举与选择

- 状态：已采纳
- 依赖：RFC 0103、RFC 0105、RFC 0109、RFC 0111

## 动机

`qbench` 默认运行完整核心负载集，以便持续门禁；调试单个回归时，重复等待全部负载会降低反馈速度。CLI 需要提供不改变默认行为的确定性枚举与单负载选择。

## 契约

1. `qbench --list` 按内建顺序逐行输出每个负载名，不输出计时记录或诊断。
2. `qbench --only NAME` 只运行精确匹配的一个负载；JSON 与文本输出格式、语义护栏、计时字段和 schema 不变。
3. 未知名称必须以退出码 2 失败，并提示使用 `--list`；`--list` 与 `--only` 同时出现也以退出码 2 失败。
4. 不指定 `--only` 时，默认完整负载集合与 RFC 0109 相同。

## 验收

`tests/cli_tools.rs` 必须验证完整枚举、单负载 JSON、未知名称和冲突参数；测试门禁先构建当前 CLI 二进制，避免 MSRV 环境回退到过期 target 产物；`make check` 继续执行完整 release qbench 门禁。
