# RFC 0053：名称算术复合赋值

- 状态：已采纳
- 依赖：RFC 0001、RFC 0039

名称支持 `+=`、`-=`、`*=`、`/=`、`%=` 与 `**=`，例如 `total += amount`。它们等价于先读取同一名称、以对应严格数值运算求值右侧，再以普通 `name = value` 写回；结果是写回后的值。右侧按正常表达式规则求值，非数字或未绑定名称产生运行时错误。

复合赋值只接受普通名称。成员、索引和递归解构仍不提供可变写入接口，以保持无原型、不可变公开数组/映射值；这些形式会在解析阶段被拒绝。该限制与 `?=` 的名称专属规则一致。

实现复用现有 `Load`、算术指令和 `Store`，不增加 VM 状态。验收覆盖全部六种运算、严格错误、后置循环中的复合赋值、成员/索引拒绝以及已验证字节码。
