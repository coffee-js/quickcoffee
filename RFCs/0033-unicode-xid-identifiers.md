# RFC 0033：Unicode XID 标识符

- 状态：已采纳
- 依赖：RFC 0001

## 语法与语义

标识符首字符必须是 Unicode `XID_Start` 或 `_`；后续字符必须是 Unicode `XID_Continue` 或 `_`。这允许天城文等文字中的组合附标作为续字符，例如 `स्थित`，但不允许附标单独作为首字符。ASCII 关键字仍仅在完整标识符恰为其保留拼写时生效。

实现不做 Unicode 规范化或大小写折叠：不同标量序列是不同名称。此规则避免语言悄然改写宿主输入，同时保持词法匹配可预测。

## 实现与验证

词法器使用锁定版本的 `unicode-ident` crate 提供的 XID 分类；它不影响 AST、字节码、VM、fuel 或宿主 `Value` API。测试覆盖组合附标执行、首字符拒绝和经验证 chunk；天城文可执行手册以 `स्थित` 作为端到端示例。
