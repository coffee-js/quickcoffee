# RFC 0064：缩进式映射字面量

- 状态：Accepted
- 依赖：RFC 0001、RFC 0009、RFC 0018、RFC 0063

## 摘要

QuickCoffee 支持 CoffeeScript 风格的缩进式映射字面量：

```coffee
record =
  first: 20
  nested:
    second: 22
record.nested.second
```

赋值行以单独的 `=` 结束，随后缩进块的首个有效行必须是标识符或字符串键后接 `:`。映射可以递归嵌套；同一映射内的条目可用换行或逗号分隔。显式 `{...}` 写法保持不变。

## 词法降低

词法预处理在不增加物理行的前提下，将明确的赋值/映射键缩进块降低为内部 `{` 与 `}`。这样既复用 RFC0063 的集合分隔规则，也保持源行号稳定。仅有普通赋值续行（如 `value =` 后接 `1 + 2`）时不触发降低。

映射块可出现在函数、条件和其他已有缩进体内；映射值本身可继续使用 QuickCoffee 的数组、函数和映射表达式。制表符缩进、未配对分隔符和不符合键形状的块仍按既有 Parse 错误处理。

## 非目标

本 RFC 不引入隐式函数调用、不允许任意缩进表达式自动成为映射，也不改变原型、`this` 或 JavaScript 对象语义。

## 验收

核心测试覆盖平面/递归映射、函数内映射、普通赋值续行不误判、成员读取、五种文学手册、字节码验证与已有显式映射回归。
