# RFC 0031：无限循环 `loop`

- 状态：已采纳
- 依赖：RFC 0002、RFC 0004

## 语法与语义

`loop body` 是 `while true then body` 的 CoffeeScript 风格简写。它是表达式，正常情况下不会自行结束；使用 `break` 退出，`continue` 开始下一轮。与所有循环一样，其结果为 `nil`。

无限循环不削弱资源限制：每轮的条件、跳转和体仍消耗 fuel，fuel 耗尽返回普通运行时错误。`break` 与 `continue` 只允许在此循环的词法体内，嵌套行为保持最内层原则。

## 编译与验证

解析器直接将 `loop` 规范化为 Bool 常量 `true` 的既有 `While` AST。编译器、显式 VM 调用帧与控制流验证器均复用 while 的既有路径；不增加新字节码指令或 VM 隐藏状态。

## 验收

测试覆盖缩进块中的 break、fuel 耗尽和已验证的 `loop break` chunk。
