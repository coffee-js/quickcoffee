# RFC 0065：受约束的隐式函数调用

- 状态：Accepted
- 依赖：RFC 0001、RFC 0020、RFC 0064

## 摘要

QuickCoffee 支持 CoffeeScript 风格的同一逻辑行隐式调用：

```coffee
add = (left, right) -> left + right
add 20, 22
double add 20, 22
len [1, 2, 3]
```

显式 `f(a, b)` 继续支持。无括号调用的参数由普通表达式解析，因此 `increment 2 * 3` 等价于 `increment(2 * 3)`；逗号可分隔多个参数，参数中的数组/调用 splat 规则与显式调用一致。连续隐式调用从内向外组成调用树，例如 `double increment 2`。

## 边界

隐式调用只在当前逻辑表达式中、后缀条件/推导处理之后识别；`Semi`、`Dedent`、闭合分隔符和显式二元运算会结束参数。括号调用参数仍须逗号，故 `add(20 22)` 不成为合法的无分隔参数形式。映射中 `key: f value, other: x` 的逗号保留为映射条目分隔符。带多个元素的数组参数（如 `len [1, 2]`）按集合参数识别；单元素数组与索引在无空白信息的字节码词法中有歧义，使用 `len([1])` 可明确表达。

本实现不支持跨物理行自动吞并隐式参数；需要跨行时使用显式运算续行、括号或文件中的显式调用。这一边界避免隐式调用夺取布局块和错误行号。

## 非目标

不引入 JavaScript `this`、原型方法、隐式成员查找或动态 `eval`。运行时仍通过 QuickCoffee 字节码调用约定执行，宿主函数与脚本函数共享同一严格参数校验。

## 验收

核心测试覆盖单参数、算术参数、多参数、嵌套调用、数组参数、显式调用回归、括号内缺逗号拒绝、映射逗号边界；五种文学手册和基准加入隐式调用负载。
