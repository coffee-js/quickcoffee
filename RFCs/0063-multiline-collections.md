# RFC 0063：多行集合省略逗号

- 状态：Accepted
- 依赖：RFC 0001、RFC 0009、RFC 0018

## 摘要

数组与映射字面量在多行书写时，可用物理行边界代替逗号：

```coffee
values = [
  1
  2
  3
]
record = {
  first: 1
  second: 2
}
```

同一行的逗号形式保持不变，尾逗号仍可使用。数组和映射可递归嵌套，显式逗号与换行分隔可以混用。

## 词法边界

词法器维护括号、数组、映射的分组栈；仅当当前最内层为 `[` 或 `{`、本行以完整集合项结束且没有显式续行运算符时，才注入集合分隔标记。普通括号调用不获得隐式参数分隔，因此 `sum(\n 1\n 2\n)` 仍为 Parse 错误。箭头函数体和显式运算续行不会被错误截断。

分组栈同时验证 `()`, `[]`, `{}` 的配对；错配在词法阶段报告带行号的 Parse 错误。

## 非目标

本 RFC 不开放隐式函数调用、不改变映射键规则、不允许字符串或调用参数依靠换行分隔，也不改变顶层布局块语义。

## 验收

核心测试覆盖无逗号数组、映射、嵌套集合、逗号与换行混用、调用参数拒绝、箭头函数项和分组错配；五种文学手册与中英文语法索引给出可执行示例。
