# RFC 0025：短路链式比较

## 决议

QuickCoffee 支持同一比较优先级的链：`a < b < c`、`a <= b <= c`、`a is b is c` 等价于相邻比较的逻辑与，即前者为 `a < b and b < c`。中间操作数只求值一次；任一相邻比较为 `false` 时，后续操作数不求值且整个链结果为 `false`。

链只包含严格相等/不等和数值顺序比较：`==`/`is`、`!=`/`isnt`、`<`、`<=`、`>`、`>=`。成员关系 `in`/`of` 不参与链，避免将数组或映射成员检查误读为数学关系。

## 字节码

编译器以 `Dup`、`Rotate3`、`Swap` 保留中间值，计算当前比较后通过 `JumpIfFalse` 短路。失败路径清除保存的中间值并只留下 `false`；成功路径继续使用该中间值。临时值始终位于 VM 值栈，不写入词法环境。

## 验证

`tests/rfc_core.rs` 覆盖真/假链、`is` 链、宿主回调确认中间值仅一次且最后操作数短路、生成 bytecode 验证与 `Swap` 栈下溢拒绝。
