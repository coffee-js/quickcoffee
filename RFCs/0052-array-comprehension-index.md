# RFC 0052：数组迭代下标绑定

- 状态：已采纳
- 依赖：RFC 0004、RFC 0029、RFC 0044

数组 `for` 可写一个值模式，或在其后写第二个模式接收从零开始的数组下标：`for value, index in items then value + index`。第二个模式与值模式一样支持严格递归绑定；实际使用通常是普通名称。数组 `for` 的顶层模式数量因此为一或二，映射 `for own key, value of map` 仍恰为二。

下标是迭代器访问数组时的实际位置，而不是收集结果中的序号。省略 `by` 时依次为 `0, 1, 2`；`by 2` 时依次为 `0, 2, 4`。过滤、`continue`、`break`、收集表达式和函数返回沿用既有规则；被 `when` 拒绝的项不会执行体，但不会改变后续实际数组位置。

`IterNext` 继续保存严格模式列表。数组迭代器在模式数量为二时压入值和 `Number` 下标，之后由既有原子模式匹配与环境写入路径处理。验收覆盖普通下标、步进下标、嵌套循环、模式验证以及超过两个数组绑定的解析错误。
