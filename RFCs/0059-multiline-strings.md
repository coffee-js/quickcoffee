# RFC 0059：普通多行字符串

- 状态：Accepted
- 依赖：RFC 0001、RFC 0040

## 摘要

除保留换行的三引号 heredoc 外，QuickCoffee 允许普通单引号和双引号字符串跨物理行。行间普通换行合并为一个空格，字符串内部的缩进不进入结果；因此：

```coffee
message = "hello
  world"
message == 'hello world'
```

双引号跨行字符串仍可使用 `#{expression}` 插值，单引号字符串仍为字面文本。三引号 heredoc 的保留换行/插值规则不变。

## 反斜杠续行

若一行字符串内容以一个未转义的反斜杠结束，则该反斜杠和物理换行均移除，下一行的前导排版空格也不进入结果：

```coffee
"hello\
  world" == 'helloworld'
```

连续偶数个反斜杠不触发此规则；普通转义仍由既有字符串词法处理。

## 词法与布局

词法预处理把普通多行字符串合并成一个逻辑行，再交给既有字符串扫描器；字符串内部的物理行不产生 `Semi`、`Indent` 或 `Dedent`。未闭合字符串仍是 Parse 错误，并标注起始行。字符串闭合后同一物理行的后续表达式继续正常解析。

## 验收

核心测试覆盖单引号/双引号跨行、插值、反斜杠续行、字符串内部缩进、闭合后继续表达式、未闭合错误、heredoc 回归、字节码验证与五语文学编程手册示例。
