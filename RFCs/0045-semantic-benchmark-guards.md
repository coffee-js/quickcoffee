# RFC 0045：性能基准语义护栏

- 状态：已采纳
- 依赖：RFC 0003、RFC 0004、RFC 0042、RFC 0044

每个 `benches/core.rs` 工作负载必须声明期望的最终值。基准在计时前以同一 release chunk 和 fuel 执行一次校验，并将结果转为 QuickCoffee 显示文本比较；校验失败立即终止 benchmark。校验不计入编译或执行计时，计时循环仍只消费 `black_box` 结果。

该护栏防止优化、字节码改动或语义变更让负载返回错误结果而仍被记录为性能成功。期望值、源程序、迭代数、三次样本与中位数共同构成可复核报告证据；它不替代 RFC 核心单元测试，也不把跨机器吞吐当作兼容性承诺。
