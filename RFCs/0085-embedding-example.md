# RFC 0085：可执行 Rust 嵌入示例

- 状态：已采纳
- 依赖：RFC 0002、RFC 0041、RFC 0043、RFC 0084

## 动机

嵌入 API 的文档片段不足以证明新用户可以在宿主系统中实际使用它。项目应提供一个最小、无外部依赖的 Rust 示例，并在验收中编译它，确保公开 API 与文档同步。

## 示例契约

`examples/embed.rs` 创建 `Context`，设置一个宿主全局，注册一个 `add_native` 回调，并执行读取全局和调用回调的 QuickCoffee 程序。回调只通过 `Value` 访问器和 `Error::runtime` 交互，不接触 VM 帧、环境或内部引用计数。示例必须以成功状态退出并打印 `84`。

`make check` 额外运行 `cargo test --examples`；示例不依赖网络、文件系统或 JavaScript 运行时。后续 API 变更若破坏示例，必须先更新 RFC、文档和测试。

## 验收

示例编译并运行成功，宿主全局与回调值均参与结果；错误类型和公开 `Value` 访问器可直接使用。示例作为嵌入 API 的最小回归，而非性能基准。
