# RFC 0037：严格数组区间切片

- 状态：已采纳
- 依赖：RFC 0001、RFC 0002、RFC 0008、RFC 0015

## 语法与语义

数组后缀 `items[start..end]` 取得含末端的切片，`items[start...end]` 取得不含末端的切片。两个端点都是必填表达式，按从左到右顺序各求值一次。nil 安全形式为 `items?[start..end]`；接收者为 `nil` 时直接得 `nil`，端点不求值。

端点必须是有限整数。负端点从数组末尾计数，`-1` 是最后一个元素；全部规范化后的端点必须在数组边界内，且起点不得大于末端。切片仅接受数组、始终新建不可变数组；不做 JavaScript 的字符串切片、隐式截断或原型方法调用。

## 编译与验证

解析器以 `Expr::Slice` / `Expr::SoakSlice` 表示该后缀。编译器依次压入目标、起点、末端，再发出 `Slice(inclusive)`；该指令弹出三值并压回一个数组，因此验证器要求至少三个栈值。VM 复用既有不可变数组值与 fuel 计数，不增加宿主可见状态。

## 验收

测试覆盖两种末端、负端点、越界和类型错误、nil 安全短路、端点恰好一次求值、反汇编与 chunk 验证。性能基准单独测量热循环中的切片分配路径。
