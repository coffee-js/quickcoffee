# RFC 0044：`for` 严格模式绑定

- 状态：已采纳
- 依赖：RFC 0004、RFC 0023、RFC 0042

数组迭代的值绑定可使用 RFC 0023 的任何严格模式：`for [left, right] in pairs then expression` 与 `for {point: {x, y}} in values then expression`；可选的第二个顶层模式绑定从零开始的数组下标。映射迭代仍有两个顶层绑定位置，均可为模式：`for _, value of record then expression`。数组迭代恰须一个值模式或再加一个下标模式，映射迭代恰须两个；否则为解析错误。`by` 时下标是实际数组位置（例如步长 2 得到 0、2、4）。`when`、`break`、`continue` 和收集表达式语义不变。

`IterNext` 保存模式而非名称。每轮 VM 先把所有模式递归匹配到临时绑定表；仅在全部成功时写入当前环境。故任一类型、长度或键不匹配都会在该轮报运行时错误，且既有绑定绝不被部分更新。

只有绑定名与 `_` 的既有循环走等价的直接绑定快路径；这些模式不可能匹配失败，因而无需临时表。复杂模式才使用原子匹配缓冲，避免新能力给常见循环增加不必要的分配。

验收覆盖数组和映射的模式、嵌套映射模式、`_` 忽略位、失败的原子性、错误的顶层数量，以及编译产物验证与反汇编。
