# RFC 0055：名称自增与自减

- 状态：已采纳
- 依赖：RFC 0001、RFC 0053

## 语法与语义

普通名称支持前置和后置的 `++`、`--`：

```coffee
next = ++counter
previous = counter--
```

前置形式先更新并产生新值；后置形式先产生旧值，再更新名称。两者都等价于对名称作严格
数值加一或减一，非数字或未绑定名称在运行时失败。更新只接受普通名称；成员、索引、解构
以及其他任意表达式均在解析阶段拒绝，不暴露可变对象或原型语义。

更新表达式可以出现在普通表达式、条件、函数体和循环体中。名称绑定仍写入当前词法环境，
因此 `value++ while value < 3` 与其他名称赋值一样受 fuel 限制。

## 字节码实现

编译器复用 `Load`、常量 `1`、`Add`/`Sub` 和 `Store`。前置形式留下新值；后置形式以 `Dup`
保留旧值，写回新值后弹出写回副本。无需新增 VM 指令或运行时对象，现有验证器即可证明栈平衡。

验收覆盖两种方向、前后置结果差异、循环、未绑定名称、非数字值、成员/索引拒绝及字节码验证。
