# RFC 0060：纯字面量常量折叠

- 状态：Accepted
- 依赖：RFC 0002、RFC 0050、RFC 0056、RFC 0057

## 摘要

编译器在生成字节码前折叠无副作用的纯字面量表达式，使常量算术、比较、逻辑、数组、映射和插值不必在每次执行时重复计算。动态名称、调用、宿主函数、循环、异常和可能产生严格运行时错误的表达式不折叠。

例如：

```coffee
1 + 2 * 3
```

直接生成一个常量和 `Return`，而不是 `Constant, Constant, Mul, Constant, Add`。

## 语义边界

折叠使用与 VM 相同的数值和类型规则：`//`、`%%`、位运算和移位沿用各自 RFC；位操作数不是有限有符号 32 位整数、移位计数不在 `0..31` 或其他严格类型检查失败时，编译器保留原始字节码，使错误仍在运行时以同样的 `ErrorKind::Runtime` 暴露。逻辑运算只在左值为 Bool 时折叠，短路结果仍保留实际操作数。

纯字面量数组、映射和插值可以折叠为不可变 `Value` 常量。折叠不解析名称、不调用函数，也不跨越赋值、解构、`try`/`finally` 或控制流边界，因此不会改变可观察副作用顺序。

## 验证与性能

折叠后的 `Chunk` 仍经过完整栈高/控制流验证；测试同时检查反汇编指令减少、动态和非法表达式不被误折叠、嵌套函数语义以及共享 `Program` 重复执行。基准增加常量折叠负载，记录编译和执行吞吐。
