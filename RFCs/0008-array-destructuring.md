# RFC 0008：严格数组解构赋值

- 状态：已采纳
- 依赖：RFC 0001、RFC 0002

`name, name, ... = expression` 要求右侧为数组且元素个数与名称严格相同；RFC 0071 允许数组模式最后一项写作 `tail...` 以绑定剩余数组。`_` 是显式忽略位置；其余名称在当前全局环境绑定。整个赋值表达式仍产生原数组。RFC 0023 进一步允许数组项为递归数组或映射模式。

编译器发出 `Destructure(Pattern)`，VM 在写入任一名称前检查容器种类、长度和 rest 位置，故失败不会留下部分绑定。模式默认值、映射 rest/splat 与函数参数解构中的 computed/string 键仍不支持。
