# RFC 0058：显式运算符行续行

- 状态：Accepted
- 依赖：RFC 0001、RFC 0009

## 摘要

CoffeeScript 允许把一个未完成表达式排布在多行。QuickCoffee 采纳其中可判定、不会引入隐式调用的子集：若一行的最后一个有效记号是显式运算符，下一行继续同一表达式，不产生语句分隔符。

例如：

```coffee
total = 1 +
  2 * 3
```

结果为 `7`。续行可出现在缩进块内；续行行首的空格只用于排版，不会开启或关闭 `Indent`/`Dedent` 块。续行结束后，下一物理行恢复通常的布局规则。

## 允许的续行记号

续行记号包括赋值、算术、整除/取模、位运算、移位、幂、比较、`and`、`or`、`not`、`in`、`of`。为避免把后缀非 nil 测试 `value?` 误判为未完成表达式，`?` 不在续行记号中；需要跨行回退时可将右值放入括号。箭头不属于续行记号：`->` 和 `=>` 仍然结束函数头并开启既有的缩进函数体。

圆括号、方括号和花括号中的换行本来就不产生布局分隔符；本 RFC 不改变其行为，也不负责启用省略括号调用（该能力另见 RFC 0065）或隐式成员链。

## 词法与验证

词法器只在行尾运算符后抑制 `Semi`，并在下一行暂时冻结布局栈。表达式仍由同一 Pratt 解析器生成，字节码验证器和 VM 无需新增指令。续行缺少右操作数时必须产生带源行号的 Parse 错误。

## 验收

测试覆盖顶层和缩进块内的续行、续行后布局恢复、每类运算符的代表性样例、未完成续行错误、词法记号不插入 `Semi` 以及生成字节码的验证。
