# RFC 0101：qdocco 原子输出

- 状态：已采纳
- 依赖：RFC 0083、RFC 0094

`qdocco` 生成 HTML 或 Markdown 时，先在目标文件同一目录建立带进程号的临时文件，完整写入并同步后，再以重命名替换目标文件。写入或替换失败时清理临时文件，并保留原有目标产物；目标路径仍不得与源码相同（RFC 0083）。

该契约避免磁盘错误、进程中断或宿主终止时留下半份文档。临时文件使用独占创建；同一目录中已有同名临时文件时本次生成失败而不覆盖它。

HTML 产物以 `quickcoffee.qdocco.html.v1` 的 generator meta 标识模板版本。`--incremental` 在渲染完成后读取已有目标；字节完全相同时不创建临时文件、不替换目标并报告 `unchanged`。目标不存在或内容变化时才进入上述原子写入流程。读取已有目标的其他错误必须终止生成，不能用覆盖掩盖。
