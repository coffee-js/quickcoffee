# RFC 0072：Unicode 字符串索引与切片

- 状态：已接受
- 依赖：RFC 0037、RFC 0070

## 摘要

字符串支持与数组一致的严格索引和区间切片，但边界单位定义为 Unicode 标量值，而不是 UTF-8 字节或 JavaScript UTF-16 code unit。

```coffee
text = 'a☕中'
text[1]       # '☕'
text[1..2]    # '☕中'
text[1...2]   # '☕'
```

## 语义

索引下标必须是非负、有限整数，返回一个只含单个 Unicode 标量的字符串；越界或非整数是运行时错误。切片端点按 RFC 0037 求值一次，允许负端点从标量长度末尾计数，规范化后必须落在边界内，且起点不得大于末端。含末端 `..` 与不含末端 `...` 的规则与数组相同；切片总是新建不可变字符串。

字符串索引和切片支持 nil 安全后缀：nil 接收者短路为 `nil`，下标或端点不求值。非 nil 的数组、字符串和映射类型边界仍严格；映射不支持区间切片，数组语义不变。

## 实现与验收

VM 的 `Index` 对字符串按 `chars()` 选择标量；`Slice` 先建立标量边界再重新组装 UTF-8 字符串，不暴露宿主字节偏移。验收覆盖 ASCII、三字节 Unicode、负端点、越界、非整数、端点单次求值、nil 安全、映射错误和字节码验证；性能基准单独记录字符串热路径。
