# RFC 0042：`for` 表达式收集

- 状态：已采纳
- 依赖：RFC 0004、RFC 0002

数组和映射 `for` 表达式按迭代顺序收集每次循环体的结果为新数组。`when` 为 false 的项不执行体、也不收集；`break` 返回已收集的前缀，`continue` 不收集当前项。`while`、`until` 与 `loop` 仍返回 `nil`。

编译器在迭代前压入空数组，每次体求值后发出 `Append`；该指令消费数组和值并压入追加后的数组，验证器要求两个栈值。VM 在该数组的 `Rc` 唯一时原地追加；若字节码或宿主使其共享，则按写时复制处理，因此公开的 `Value` 仍无可变数组接口。若 `for` 位于程序或块的非末尾语句、其结果必然被丢弃，编译器直接发出不收集的迭代路径，避免无用数组分配；此优化不改变可观察结果。`break` 的既有 `IterEnd` 清理保持不变。测试覆盖普通、过滤、break、反汇编、被丢弃的顶层与块内循环，以及 chunk 验证。
