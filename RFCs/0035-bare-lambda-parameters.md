# RFC 0035：无括号名称 lambda 参数

- 状态：已采纳
- 依赖：RFC 0001、RFC 0021、RFC 0026

## 语法与语义

除既有 `(x, y) -> body` 外，普通绑定名可省略参数括号：`x -> body` 和 `x, y -> body`。它们创建与括号形式相同的词法闭包；`=>` 作为无 `this` 语义的同义箭头也可使用。

为保持单遍无歧义解析，无括号形参只接受一个或多个普通名称。默认参数、rest 参数、`_` 忽略位和数组/映射解构均必须使用括号形式。例如 `(value = 1) -> value`、`(values...) -> values` 与 `([left, right]) -> left` 有效，`value = 1 -> value` 与 `values... -> values` 无效。

## 编译与验证

解析器将无括号名称列表直接规范化为既有 `Param { Pattern::Bind, default: None }`。后续函数常量、调用帧绑定、闭包捕获、字节码验证和 VM 调用路径完全复用既有实现。

## 验收

测试覆盖单名称作为实参、多名称闭包捕获、默认/rest 无括号拒绝和已验证 chunk。性能基准单独覆盖无括号 lambda 的编译与执行。
