# RFC 0056：整除与向下取模

- 状态：已采纳
- 依赖：RFC 0001、RFC 0053

## 运算

QuickCoffee 增加 CoffeeScript 风格的 `//` 与 `%%`：

- `a // b` 先作严格数值除法，再取 `floor(a / b)`；例如 `-7 // 5` 为 `-2`。
- `a %% b` 是 dividend-dependent modulo，定义为 `(a % b + b) % b`；例如 `-7 %% 5` 为 `3`，
  `7 %% -5` 为 `-3`。普通 `%` 仍保持余数（符号随被除数）。

两侧必须是 Number；除零沿用 IEEE-754 `f64` 的无穷大或 `NaN` 行为，不引入隐式转换或整数类型。
两种运算的优先级与 `/`、`%` 相同，均低于幂运算 `**`。

## 复合赋值与实现

名称可写 `name //= value` 与 `name %%= value`，复用 RFC 0053 的名称专属规则；成员、索引和
解构仍在解析阶段拒绝。

编译器发出新的 `FloorDiv`、`Modulo` 算术指令。VM 使用 `f64::floor` 与显式 `(a % b + b) % b`
实现，保持负除数的 CoffeeScript 结果；验证器将二者视作普通二元栈运算。

验收覆盖正负操作数、负除数、普通 `%` 对照、两种复合赋值、严格错误、成员拒绝和字节码验证。
