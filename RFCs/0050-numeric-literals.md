# RFC 0050：数值字面量形式

- 状态：已采纳
- 依赖：RFC 0001、RFC 0034

`Number` 仍以 IEEE-754 `f64` 表示，但词法器接受常用的无后缀数值形式：十进制整数/小数、十六进制 `0x`/`0X`、二进制 `0b`/`0B`、八进制 `0o`/`0O`，以及十进制科学计数法（如 `1.5e-2`）。非十进制形式必须至少含一个合法数字；科学计数法必须含完整指数。

非十进制整数先按无符号整数解析，再转换为 `f64`，因此仍遵循 QuickCoffee 的单一 Number 类型，不引入 BigInt 或 JavaScript 隐式转换。范围字面量的 `..` 与 `...` 分隔符优先于普通小数点解析。

验收覆盖四种进制、科学计数法、算术组合、非法空数字/指数的词法错误、源码行位置和已验证字节码。数值溢出或超过 `f64` 精确整数范围不改变类型契约，显示与运算遵循 `f64` 语义。
