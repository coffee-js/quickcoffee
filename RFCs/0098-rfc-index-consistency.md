# RFC 0098：RFC 索引一致性门禁

- 状态：已采纳
- 依赖：RFC 0000、RFC 0097

## 动机

设计文档、README 和实现契约必须同步。历史上新增 RFC 后，README 或 RFC 0000 的“最新编号”容易滞后，造成用户无法判断当前规范范围。该问题不应依赖人工审阅才能发现。

## 契约

集成测试递归读取 `RFCs/*.md`，要求：

1. 文件名以四位十进制编号开头，编号从 `0000` 连续到最新 RFC，不得有间隙；
2. 每份 RFC 有 `# RFC` 标题及中文 `状态：` 或英文 `Status:` 字段；
3. README 链接最新 RFC 文件名；
4. RFC 0000 明确提及最新编号。

该门禁只检查文档元数据，不执行文档中的 QuickCoffee 源码；文学手册和 RFC 语义仍由 `qdocco`、`qtest` 与核心测试分别验收。

## 验收

`make check` 必须包含该集成测试。新增 RFC 时，若忘记连续编号、状态字段或两个索引引用，测试应失败并给出具体断言。
