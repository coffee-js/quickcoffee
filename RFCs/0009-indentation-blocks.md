# RFC 0009：空格缩进块

- 状态：已采纳
- 依赖：RFC 0001、RFC 0002

## 布局规则

在顶层或另一缩进块中，行首空格数增加时产生 `Indent`，减少时产生一个或多个 `Dedent`。制表符用于行首缩进是解析错误；减少到从未出现的列数也是解析错误。空行和纯注释行不改变布局。括号、数组和映射字面量的未闭合分隔符内，换行不产生布局标记。

## 块体

`if`、`unless`、`while`、`for`、`->`、`=>` 与工厂 `class` 在 `then` 或箭头后可使用单行表达式，或在换行后接缩进的多语句体。块的值为最后一条语句的值；空块为 `nil`。`else` 允许与结束的缩进块同列。

## 编译

解析器把布局体降为 `Block(statements)`，编译器丢弃除最后一个外的语句值。因此不需要 VM 的块作用域指令，且块不改变现有字节码验证模型。

## 验收

必须测试条件、循环和函数的多语句缩进体、`else` 退格、制表符错误和不一致缩进错误；所有原有单行 `then` 程序必须保持可执行。
